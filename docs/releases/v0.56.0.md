# Autolith 0.56.0

## Experimental ACP support

- Add experimental editor sessions over the Agent Client Protocol. Configure an ACP-compatible editor to launch `autolith acp`, and authenticate your provider first with `autolith auth`.
- Stream responses, visible reasoning, tool activity, and plans. Use editor permission modes, cancel prompts, and load durable conversations by ID.
- Combine client-supplied stdio and HTTP MCP servers with native registrations for each session.

The initial integration supports text prompts, resource links, and embedded text resources. Authentication and provider/model configuration use native Autolith settings. Editor session-history browsing, model selectors, and structured diff/terminal views are follow-up work.

## Terminal

- Jump between user and assistant messages with Ctrl-PageUp and Ctrl-PageDown, skipping reasoning and tool activity.
- Open transcript links in your browser and copy fenced code blocks to the clipboard, including through SSH and local-session attachments.
- Update the fullscreen legend and print resume instructions after restoring the terminal on exit.
- Keep terminal input responsive while evaluating Lisp and running application commands.

## Runtime and builds

- Avoid duplicate papercut reports and record acknowledgements in the conversation.
- Look up Lisp definitions through recorded dependency source locations.
- Derive Nix Git dependency versions from `qlfile.lock`.
- Use ls-compat for file publication and handoff process discovery.

Update with `(update)`.
