# Autolith 0.54.0

## Models

- Add GPT-6.1 Sol to the ChatGPT model catalog and use it as the default model.

## Configuration

- Remove the deprecated configuration accessors and copying helpers, preference shims, and preference-format 1 through 7 migration. Read settings with `config` and copy configurations with `configuration-copy`.

## Terminal

- Add the opt-in `--almighty` theme, with its own palette and boot screen.
- Wait for Space on the boot screen, rotate startup tips, and handle boot-screen input through the responsive reader.
- Restore client default colors after screen handoff.

## Builds

- Synchronize the Nix cl-colorist pin with the Qlot dependency and include true-color styling support.
- Build and validate tagged Windows packages independently of the complete test suite. Upload validated package-CI artifacts before running the tests, with test failures reported in CI.
- Resolve the search helper below the configured source root.

Update with `(update)`.
