# Autolith 0.53.2

## Release reliability

- Bundle the private process-group helper in POSIX release archives and use it when building images from a read-only installation.
- Include the Windows release verification fix from v0.53.1.

## Commands and tools

- Add `autolith uninstall` to remove installed binaries and managed caches while preserving conversations, credentials, configuration, and other user data.
- Accept `self.define` as an alias for `self.redefine`.
- Answer deferred provider tool searches from the local registry and replay loaded tool definitions between requests.

This release includes the plain-text page retrieval added in v0.53.0. Update with `(update)`.
