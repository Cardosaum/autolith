# Autolith 0.58.0

## Help

- Replace the long command dump with a compact, colored help overview organized by topic.
- Look up a section, command, Lisp operation, tool, or tool namespace with `(help :models)`, `(help 'resume)`, or `(help "resource.edit")`. Tool help includes required and optional arguments from the current tool schema.
- Add topic-aware help completion and clearer guidance for unknown subjects.

## Text editing and terminal fixes

- Fix modified Enter keys being decoded incorrectly.
- Fix the fullscreen composer cursor position on wrapped lines and the extra space shown when text exactly fills a row.
- Preserve the original file and an occupied temporary file when a file edit encounters a staging-name collision.
- Report a detached session's launcher exit status to its terminal.

## Other fixes and improvements

- Fix the Windows PowerShell installer failing while writing the selected-release pointer ([#80](https://github.com/lambda-symbolics/autolith/issues/80)). Check installation and reinstallation in PowerShell 5.1 and 7.
- Fix native Windows detached launches without a handoff ticket and read-only Git fixture cleanup in Windows CI.
- Accept a sequence of forms in `lisp.eval` and `self.eval`, reading each form after the previous one runs. Include compiler and test output in failed Lisp tool results.
- Send image attachments to Gemini Code Assist as inline image data.
- Ask for full access when a tool needs a path outside the workspace instead of rejecting the path outright.
- Enforce search time budgets and reject unsupported constraints that would accidentally match everything or nothing.

Update with `(update)`.
