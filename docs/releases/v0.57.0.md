# Autolith 0.57.0

## Conversation history

- Read and search durable conversation histories through `conversation:` resources, replacing the separate session history tools.
- Include compaction summaries when replaying a conversation.

## ACP

- Preview the main tool argument in editor tool-call titles, with bounded, single-line text.
- Batch visible reasoning fragments and deliver pending thoughts before permission requests and prompt completion, cancellation, or errors.
- Fix Windows ACP startup by using SBCL's native standard-I/O handles.
- Wait for subprocess cleanup before reporting the exit status and retained stderr diagnostics.

The title previews and reasoning batching adapt Lennart Grosse's ACP work to the shared `agentcomms` library.

## Shared libraries and builds

- Use `argo` for the shared JSON value model and codec.
- Use `setinka` for settings and configuration sources.
- Move filesystem, process, path-confinement, and UTF-8 operations behind `ls-compat`.
- Reuse the bootstrap ASDF cache in Windows source checks instead of recompiling dependencies in each isolated source launcher.
- Match the fullscreen legend background to the transcript.

Update with `(update)`.
