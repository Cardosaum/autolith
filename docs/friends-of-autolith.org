#+title: Friends of Autolith: remaining candidates
#+date: 2026-09-01
#+options: toc:2

Remaining candidates from the 2026-09-01 review, pruned against Autolith
0.56.0 on 2026-10-03. Source references describe that historical review.

* samizdat (yogthos)

** Version/session outcome metadata (RFC-001)

Associate sessions with the settings and prompt versions they used and
how those sessions ended. Git commits and mutation journals already supply
rationale. Keep version identifiers and outcomes in durable metadata for
on-demand inspection, outside the provider prompt.

** Tool-result redaction (RFC-003)

Audit redaction across tool-result dispatch, before transcript persistence
and provider projection. ACP already redacts its configured environment
and header values; other tools need the same coverage assessment.

Redact known secret values available during scoped credential use. Keep
redaction state within that scope. Avoid speculative secret-shape matching
that would corrupt ordinary output such as build hashes.

** Recoverable serialization failures (RFC-009)

Audit tool-result projection and conversation writes for unencodable
values. Use typed conditions and useful restarts, preserving the valid
durable prefix and bounded, portable diagnostic data. Arbitrary printed
Lisp objects are unsuitable substitutes for structured durable records.

** Bounded continuation probes (RFC-004)

An opt-in, tool-disabled probe could test one next move from an unchanged
conversation prefix. Bound requests and cost, including uncached input,
and reuse the cached prefix. Keep probe results outside the primary
history unless selected. This is narrower than the original prompt A/B
and multi-candidate driver proposal.

* fractal-engine (DeadMeme5441)

** Delegation cost reporting

Report parent-turn usage separately from each child subtree, then join
them without double counting. Derive the report from existing task
artifacts and inference traces, including failed calls. Inspect it on
demand rather than adding accounting tables to every prompt.

* cl-sm-harness (browep)

** Local terminal image previews

Optional local previews through kitty graphics or sixel, independent of
provider image input. The historical comparison used a Playwright-rendered
chat tile; Autolith's presentation belongs in its terminal adapters.

* Steering provenance

samizdat's interventions queue recorded the issuer of each directive.
Autolith already persists steering identifiers and acknowledges durable
consumption. Extend those records with the issuing client or session for
on-demand inspection, rather than repeating provenance in model context.
